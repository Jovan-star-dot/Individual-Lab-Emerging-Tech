# Innovation and Disruption Agent

Assignment 3 student-specialist draft built from the MASY1800 Common Emerging Technology Agent Scaffold v1.0.

- `specialist_instructions.md`: bounded analytical framework and output mapping.
- `innovation_classification_criteria.md`: explicit category and disruption-rating rules.
- `cases/`: primary and context-contrast inputs.
- `records/agent_record.md`: test and judgment record, to be completed after prompt generation and response validation.
- `responses/`: reserved for validated ChatGPT JSON outputs.

Do not modify `core/`; it is the frozen common architecture.
